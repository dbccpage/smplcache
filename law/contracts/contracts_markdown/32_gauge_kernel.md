# GaugeOp Kernel

## Classification
**Subsystem:** State operator
**Signature:** `S → S`
**Role:** Same-carrier zero-cost equivalence transformation.

## Contract
A `GaugeOp` transforms the state along a gauge orbit without altering the true topological or cohomological information.

**Must Preserve:**
* Obstruction class.
* Area-lock mass.
* Admissible context behavior.

**Must Not:**
* Reduce true obstruction.
* Change carrier.
* Erase witness.
