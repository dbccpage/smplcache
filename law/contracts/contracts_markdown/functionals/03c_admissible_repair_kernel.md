# Admissible Repair Contract

## Classification
**Subsystem:** Cohomological Semantics
**Role:** Licensed local displacement.

## Contract
An `AdmissibleRepair` is a licensed local displacement generated by $d_0$ or declared gauge/reducer action inside the current carrier.

**Must be:**
* Same-carrier
* Typed
* Finite
* Replayable
* Non-lifting
* Non-semantic

**Must Not be:**
* Optimization trick
* Solver improvement
* Explanation
* Reinterpretation
* Lift
* Adapter conversion
