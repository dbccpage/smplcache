## 1. Top-Level OS Architecture

The following systems define the mechanical execution and governance of the OS.

### General Theory / Constitution
Defines the mathematical boundaries of the system: what counts as structure, obstruction, lift, witness, proof, replay, authority, and admissibility.

### Kernel
The small, trusted semantic core. It owns contracts, type laws, evidence laws, replay laws, and lift legality.

### Artifact Families
The fundamental separation of object types to prevent semantic leakage. The system explicitly separates:
* **StructureArtifact** (schemas, definitions, topologies)
* **FactEnvelope** (measured realities, bounds)
* **DecisionEnvelope** (judgments, policies)
* **Action** (state transitions, operator executions)
* **Record** (traces, historical captures)

### Runtime
The execution layer. Executes engines, maintains state, tracks budgets, records traces, manages rollback, and ensures deterministic replay.

### Codex
The registry of **executable formal objects**:
* Operators
* Reducers
* Generators
* Solvers
* Functionals
* Evaluators
* Adapters

> **Invariant**: The Codex contains callable, typed machinery. It is not an encyclopedia.

### Encyclopedia
The registry of **human/mathematical knowledge descriptions**:
* Definitions
* Theorems
* Domains
* Historical names
* Semantic annotations
* References

> **Invariant**: The Encyclopedia explains; it does not execute.

## 2. Expressivity Geometry (Coordinate Axes)

The OS measures conceptual sophistication along a 3-axis coordinate system. 

> **Critical Correction**: Tier and Meta Level are not the same thing. They measure different axes. Do not collapse them into a single ladder.

* **Operator Level**: The sophistication of transformations available *inside* a carrier.
* **Meta Level**: The expressivity of the carrier / governance / reflection system itself.

### The 3-Axis Coordinate System

1. **Knowledge Domain**: e.g., calculus, topology, GR, category theory, governance.
2. **Operator Height**: The fine-grained operator algebra position (e.g., 1..420).
3. **Meta Height**: The structural expressivity of the governance system (e.g., 0..1124).

## 3. The Level System Definitions

### Level System
The global "expressivity stratum" definition. This captures MSS levels, Meta levels, operator algebra height, governance levels, and reflection levels.

### Tier
A coarse band of related operator levels.
* *Tier 1*: elementary calculus / analysis operators
* *Tier 2*: linear algebra / topology
* *Tier 3*: functional analysis / PDEs

### Operator Level
A fine-grained height index inside the operator algebra.
* *Level 1*: arithmetic rewrite
* *Level 7*: Taylor / integration primitives
* *Level 177*: mature human mathematical-scientific operator closure
* *Level 420*: full declared operator tower ceiling

### Operator
The actual callable morphism living at a specific operator height.
