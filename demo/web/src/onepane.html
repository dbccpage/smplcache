Change one row. The cached answer fixes itself, or says why it won't.

Redis holds the answer but not which rows it came from, so every write throws it away. SmplCache makes one of three moves per change, and never guesses.

KEEPChanged column isn't in the query.
FIX IN PLACELog has old and new value: add the difference.
REREADLog can't show the difference: read again.
